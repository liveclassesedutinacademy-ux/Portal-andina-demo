## (3) Qué falta por nivel

Ningún nivel está completo.

- **Proyecto (a medias):** el contexto está casi al día. Faltan en el README el mapa de `docs/`, las variables de entorno, el aviso del e2e y la forma de trabajo; y en el contexto, las limitaciones conocidas (la API confía en el `vendedorId` del cliente).
- **Módulo (a medias):** los endpoints sí están documentados. No existen las reglas de cada campo, el catálogo de mensajes, las rutas de la web, los errores generales de la API, cómo se prueba cada aplicación ni cómo funcionan las migraciones.
- **Decisión (a medias):** existen las decisiones por historia, pero están repartidas y las historias no las incorporan. No existe ningún registro de decisiones de arquitectura: por qué `node:sqlite`, por qué `vendedorId` sin autenticación, por qué no hay un paquete compartido entre la web y la API, por qué el `POST` ignora y el `PUT` rechaza, ni la excepción a zod en los parámetros.
