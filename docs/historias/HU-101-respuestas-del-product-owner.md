# HU-101 · Respuestas del product owner

Respuestas del product owner de Distribuidora Andina (empresa ficticia) a las preguntas P1 a P11 de la historia reescrita.

| Pregunta | Respuesta |
|---|---|
| P1. Campos obligatorios | Opción (b): todos obligatorios menos el correo. El tipo de documento también es obligatorio. Máximo 100 caracteres por campo de texto. |
| P2. Formato del teléfono | Se quitan espacios y guiones; lo que queda deben ser solo dígitos, de 7 a 10. Se guarda tal como lo escribió el vendedor. La misma regla vale para la edición (HU-102). |
| P3. Correo | Opción (a): opcional; si se escribe, debe tener forma de correo (texto, @, dominio con punto). La misma regla vale para la edición. |
| P4. Duplicado en otra zona | Opción (a): solo el mensaje «Este tendero ya está registrado.», sin datos de la otra zona. |
| P5. Duplicado de un tendero inactivo | Opción (c): se rechaza con el mensaje «Este tendero ya está registrado y está inactivo. Comunícate con la oficina comercial.» |
| P6. Estado inicial | Opción (a): `activo`. |
| P7. Vendedor asignado | Opción (a): el vendedor que lo registra. La zona es la de ese vendedor. |
| P8. Documentos que empiezan por 999 | Opción (b): se aceptan en todos los ambientes durante el sprint 1. |
| P9. Después de guardar | Opción (a): vuelve a la lista de tenderos con el mensaje «Tendero registrado». |
| P10. Formato de papel | Opción (a): no trae otros datos. |
| P11. Normalización adicional | Opción (b): el PA se convierte a mayúsculas antes de validar. El RT sin guion se rechaza. |

Los mensajes de error marcados [Propuesta] en la historia reescrita quedan aprobados tal como están.
